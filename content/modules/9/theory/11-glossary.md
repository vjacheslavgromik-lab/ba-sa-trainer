**Как пользоваться словарём.** Здесь собраны сокращения и понятия модуля. В главах каждое сокращение расшифровано при первом упоминании, а здесь их можно найти все сразу.

## Сокращения

| Сокращение | Расшифровка | Что это | Глава |
|---|---|---|---|
| API | Application Programming Interface, «программный интерфейс приложения» | набор операций и правил, через которые одна программа обращается к другой | 1 |
| HTTP | Hypertext Transfer Protocol, «протокол передачи гипертекста» | протокол «запрос — ответ», на котором работает большинство веб-API | 2 |
| HTTPS | HTTP поверх соединения, защищённого TLS | защищённый вариант HTTP | 2 |
| TLS | Transport Layer Security, «безопасность транспортного уровня» | шифрование и проверка подлинности соединения | 2 |
| TCP | Transmission Control Protocol, «протокол управления передачей» | надёжная передача данных между программами по сети | 2 |
| IP | Internet Protocol, «межсетевой протокол» | адресация и доставка пакетов данных в сети | 2 |
| URI | Uniform Resource Identifier, «единый идентификатор ресурса» | адрес, определяющий ресурс | 2 |
| URL | Uniform Resource Locator, «единый указатель ресурса» | URI, который ещё и показывает, как найти ресурс | 2 |
| JSON | JavaScript Object Notation, «запись объектов JavaScript» | текстовый формат данных: объекты, массивы, числа, строки | 3 |
| XML | Extensible Markup Language, «расширяемый язык разметки» | формат данных, размеченных тегами | 3 |
| UTF-8 | формат преобразования символов Юникода в байты | кодировка, в которой JSON передают между системами | 3 |
| SOAP | в ранних версиях Simple Object Access Protocol; в версии 1.2 не аббревиатура | протокол обмена XML-сообщениями с конвертом | 5 |
| REST | Representational State Transfer, «передача состояния представления» | архитектурный стиль; API строятся вокруг ресурсов | 6 |
| RPC | Remote Procedure Call, «вызов удалённой процедуры» | вызов функции другого приложения по сети | 4 |
| SQL | Structured Query Language, «язык структурированных запросов» | язык запросов к реляционным базам | 4 |
| YAML | не расшифровывается в курсе | текстовый формат записи структур, удобный для чтения человеком | 8 |
| OAS | OpenAPI Specification, «спецификация OpenAPI» | стандарт описания HTTP API | 8 |
| UML | Unified Modeling Language, «унифицированный язык моделирования» | язык моделирования, в котором есть диаграммы последовательности и компонентов | 8, 10 |

## Понятия

| Термин | Что значит | Глава |
|---|---|---|
| Поставщик и потребитель | поставщик предоставляет операции API, потребитель их вызывает | 1 |
| Интерфейс (инкапсуляция) | приложение скрывает внутреннее устройство и выставляет наружу только операции | 1 |
| Клиент | сторона, которая отправляет запрос | 2 |
| Сервер | сторона, которая принимает запрос и отправляет ответ | 2 |
| Протокол | договорённость о порядке и виде обмена сообщениями | 2 |
| Ресурс | объект, которым управляет API: студент, курс, запись на курс | 2, 6 |
| Представление | описание состояния ресурса в передаваемом виде, например JSON | 2 |
| Метод HTTP | действие над ресурсом: GET, POST, PUT, DELETE | 6 |
| Код состояния | трёхзначное число в ответе, показывающее результат | 6 |
| Идемпотентный метод | метод, повторный вызов которого не меняет результат | 6 |
| Заголовок и тело | служебная часть сообщения и сами данные | 2, 3 |
| Сообщение | наименьшая единица данных, передаваемая между приложениями | 3 |
| Формат данных | договорённость о том, как записаны данные: XML, JSON | 3 |
| Слабое связывание | приложения мало зависят друг от друга | 4 |
| Синхронно и асинхронно | отправитель ждёт ответа или продолжает работу | 4 |
| Семантический диссонанс | разное понимание одного понятия в разных приложениях | 4 |
| Конверт (Envelope) | корневой элемент SOAP-сообщения | 5 |
| Коллекция ресурсов | набор однотипных ресурсов: `/students` | 6 |
| Артефакт документирования | документ или модель, по которым работают другие участники проекта | 8 |
| Спецификация API | формальное описание операций, данных и ответов API | 8 |
| Шаблон пути | запись `{id}` в адресе: на её место подставляется значение | 8 |
| Схема данных | описание типов и обязательных полей тела запроса или ответа | 8 |
| Каталог ошибок | перечень кодов ошибок: когда возникают, что делать клиенту | 8 |
| Коллекция Postman | файл с запросами, папками и тестами | 9 |
| Переменная | значение, которое подставляется в запросы, например `{{baseUrl}}` | 9 |
| Диаграмма последовательности | диаграмма, где сообщения упорядочены во времени сверху вниз | 10 |
| Линия жизни | пунктирная вертикальная линия участника на диаграмме последовательности | 10 |
| Диаграмма компонентов | диаграмма частей системы и зависимостей между ними | 8 |
