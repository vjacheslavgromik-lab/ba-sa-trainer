**Как пользоваться словарём.** Здесь собраны сокращения и понятия модуля. В главах каждое сокращение расшифровано при первом упоминании, а здесь их можно найти все сразу.

## Сокращения

| Сокращение | Расшифровка | Глава |
|---|---|---|
| ISO | International Organization for Standardization, Международная организация по стандартизации | 1 |
| FIT | Framework for Integrated Test, каркас для интегрированного тестирования | 2 |
| UAT | User Acceptance Testing, приёмка пользователями | 2 |
| IEEE | Institute of Electrical and Electronics Engineers, Институт инженеров по электротехнике и электронике | 3 |
| QA | quality assurance, контроль качества | 4 |
| VCS | Version Control System, система контроля версий | 5 |
| BDD | Behavior-Driven Development, разработка через поведение | 6 |
| CI | Continuous Integration, непрерывная интеграция | 6 |
| CD | Continuous Delivery, непрерывная поставка | 6 |
| IDE | Integrated Development Environment, среда разработки | 7 |

## Понятия

| Термин | Значение | Глава |
|---|---|---|
| Квалификационное тестирование | проверка ПО и системы перед приёмкой | 1 |
| Модульный тест | проверка изолированного фрагмента кода | 2 |
| Интеграционный тест | проверка совместной работы компонентов | 2 |
| Приёмочный тест | проверка, что история сделана так, как задумал заказчик | 2 |
| Регрессионное тестирование | поиск потерянных возможностей и вернувшихся ошибок после изменений | 2 |
| План тестирования | документ о целях, ресурсах и процессе тестирования | 3 |
| Тест-кейс | вход, условия, шаги и ожидаемый результат для одной цели | 3 |
| Позитивный, негативный кейс | проверка нормального и неправильного поведения | 3 |
| Граничные значения, классы эквивалентности | приёмы выбора тестовых данных | 3 |
| Матрица трассируемости | таблица связей требований с дизайном, кодом и тестами | 4 |
| Система контроля версий | хранение истории изменений файлов | 5 |
| Снимок, фиксация | состояние файлов и операция его записи в Git | 5 |
| Конвейер сборки | цепочка автоматических этапов проверки версии | 6 |
| Живая документация | отчёт, построенный из автоматизированных приёмочных критериев | 6 |
| DevOps | общая ответственность разработки и эксплуатации | 6 |
| Парадигма программирования | способ структурировать программу | 7 |
| Фреймворк, библиотека | управляет вашим кодом и вызывается вашим кодом | 7 |
