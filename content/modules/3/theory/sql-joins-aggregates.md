## 1. Агрегирующие функции

COUNT, SUM, AVG, MIN и MAX сворачивают набор строк в одно значение (с. 182). `COUNT(*)` считает строки, а `COUNT(столбец)` пропускает NULL. AVG тоже игнорирует NULL, поэтому студент без оценок не влияет на среднее.

## 2. GROUP BY и HAVING

GROUP BY собирает строки с одинаковым значением в группы и вычисляет агрегаты для каждой группы (с. 184). В списке SELECT при группировке допустимы только столбцы из GROUP BY и агрегирующие функции.

HAVING фильтрует группы, WHERE фильтрует строки до группировки. В HAVING обычно стоит агрегирующая функция (с. 185):

```sql
SELECT course_id, COUNT(*) AS cnt
FROM enrollments
GROUP BY course_id
HAVING COUNT(*) > 1;
```

## 3. Подзапросы

Подзапрос — вложенный SELECT внутри WHERE или HAVING внешнего запроса (с. 187). Многие задачи можно решить и подзапросом, и соединением. Соединение нужно, когда в результате требуются столбцы из нескольких таблиц.

## 4. Соединения таблиц

Соединение (JOIN) объединяет строки таблиц по условию, обычно «внешний ключ = ключ» (с. 191–195):

```sql
SELECT s.name, c.title
FROM students s
JOIN enrollments e ON e.student_id = s.id
JOIN courses c ON c.id = e.course_id;
```

Внешние соединения добавляют в результат и строки, для которых не нашлось пары (с. 196–198). Различаются они тем, строки какой таблицы сохраняются. Столбцы таблицы, где пары нет, заполняются NULL:

- INNER JOIN (или просто JOIN): только строки с парой в обеих таблицах (с. 191–195).
- LEFT JOIN: все строки левой таблицы (с. 197).
- RIGHT JOIN: все строки правой таблицы (с. 197).
- FULL JOIN: все строки обеих таблиц (с. 198).

RIGHT JOIN — зеркальное отражение LEFT JOIN: запрос с ним можно переписать через LEFT JOIN, поменяв таблицы местами. Курсы вместе с записями, включая курс без студентов:

```sql
SELECT c.title, e.student_id
FROM enrollments e
RIGHT JOIN courses c ON c.id = e.course_id;
```

FULL JOIN нужен, когда важны строки с обеих сторон: и студенты без записей, и курсы без студентов. Если студента или курса не нашлось, его столбцы будут NULL:

```sql
SELECT s.name, c.title
FROM students s
JOIN enrollments e ON e.student_id = s.id
FULL JOIN courses c ON c.id = e.course_id;
```

В нашей учебной базе этот запрос вернёт и строку «Тестирование API» с пустым именем студента. RIGHT и FULL JOIN поддерживаются не во всех СУБД (в старых версиях SQLite их нет); песочница и проверка кейсов используют версию, где они работают.

Левое соединение нужно, когда требуется показать и «пустые» объекты, например курсы без записавшихся студентов. В таком случае считают `COUNT(e.student_id)`, а не `COUNT(*)`: иначе курс без студентов получит 1 вместо 0.
