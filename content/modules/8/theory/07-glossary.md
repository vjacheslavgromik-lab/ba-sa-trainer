**Как пользоваться словарём.** Здесь собраны сокращения и понятия модуля. В главах каждое сокращение расшифровано при первом упоминании, а здесь их можно найти все сразу.

## Сокращения

| Сокращение | Расшифровка | Глава |
|---|---|---|
| СУБД | система управления базами данных (Database Management System) | 1 |
| SQL | Structured Query Language, язык структурированных запросов | 1 |
| TP-монитор | Transaction Processing monitor, монитор обработки транзакций | 1 |
| OLTP | On-Line Transaction Processing, оперативная обработка транзакций | 1 |
| HTTP | HyperText Transfer Protocol, протокол передачи гипертекста | 3 |
| API | Application Programming Interface, программный интерфейс | 3 |
| GDPR | General Data Protection Regulation, Общий регламент по защите данных | 4 |

## Понятия

| Термин | Значение | Глава |
|---|---|---|
| Клиент, сервер | клиент отвечает за интерфейс и логику, сервер — за доступ к данным | 1 |
| Двухуровневая архитектура | клиент плюс сервер базы данных | 1 |
| Трёхуровневая архитектура | клиент, сервер приложений, сервер базы данных | 1 |
| «Тонкий» и «толстый» клиент | клиент с небольшой и с большой долей логики | 1 |
| Слой | логическая часть системы со своей ответственностью | 2 |
| Презентация, предметная область, доступ к данным | три основных слоя | 2 |
| Монолит | приложение как одна единица развёртывания | 3 |
| Микросервис | небольшой независимо развёртываемый сервис вокруг бизнес-возможности | 3 |
| Согласованность в конечном счёте | данные согласуются не сразу, а через некоторое время | 3 |
| Масштабный куб | модель трёх осей масштабирования X, Y, Z | 4 |
| Шард | раздел данных с собственной копией приложения | 4 |
| Компонент | исполняемая программа или библиотека кода | 5 |
| Диаграмма компонентов | компоненты и зависимости между ними | 5 |
| Узел | вычислительный ресурс на диаграмме размещения | 6 |
| Диаграмма размещения | узлы, процессы на них и соединения между узлами | 6 |
