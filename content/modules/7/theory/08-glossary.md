**Как пользоваться словарём.** Здесь собраны сокращения и понятия модуля. В главах каждое сокращение расшифровано при первом упоминании, а здесь их можно найти все сразу.

## Сокращения

| Сокращение | Расшифровка | Глава |
|---|---|---|
| INVEST | Independent, Negotiable, Valuable, Estimatable, Small, Testable | 2 |
| BDD | Behavior-Driven Development, разработка через поведение | 3 |
| NUTs | Nebulous Units of Time, неопределённые единицы времени | 4 |
| MVP | Minimum Viable Product, минимальный жизнеспособный продукт | 7 |
| SPIDR | Spike, Paths, Interfaces, Data, Rules | 7 |
| DEEP | Detailed appropriately, Estimated, Emergent, Prioritised | 7 |

## Понятия

| Термин | Значение | Глава |
|---|---|---|
| User Story | короткая запись функции, ценной для пользователя или заказчика | 1 |
| Card, Conversation, Confirmation | карточка, разговор, подтверждение: три части истории | 1 |
| Эпик | слишком крупная история, которую делят | 1 |
| Spike | ограниченное по времени исследование перед оценкой или разбиением | 2 |
| Ломтик пирога | разбиение истории так, чтобы каждая часть проходила через все слои | 2 |
| Замкнутая история | история, заканчивающаяся достижением понятной цели | 2 |
| Критерии приёмки | тесты истории, показывающие, что она готова | 3 |
| Gherkin | формат сценариев Given, When, Then | 3 |
| Scenario Outline | сценарий с таблицей примеров | 3 |
| Story point | относительная мера размера истории | 4 |
| Скорость | число story points, выполняемое за итерацию | 4 |
| Триангуляция | оценка истории по сравнению с уже оценёнными | 4 |
| Job Story | запись через ситуацию, мотивацию и результат | 5 |
| Карта историй | двумерная раскладка бэклога: активности, задачи, детали | 6 |
| Хребет | верхний ряд карты: крупные активности пользователя | 6 |
| Ходячий скелет | минимальная сквозная рабочая версия системы | 6 |
| Validated learning | проверенное знание о клиентах, получаемое с MVP | 7 |
