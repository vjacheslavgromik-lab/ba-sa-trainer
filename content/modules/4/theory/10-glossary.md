**Как пользоваться словарём.** Здесь собраны сокращения и понятия модуля. В главах каждое сокращение расшифровано при первом упоминании, а здесь их можно найти все сразу.

## Сокращения

| Сокращение | Расшифровка | Что это | Глава |
|---|---|---|---|
| ER | Entity-Relationship, «сущность — связь» | модель данных из сущностей, связей и атрибутов | 2 |
| СУБД | система управления базами данных (Database Management System, DBMS) | программа, которая создаёт базу и управляет доступом к ней | 1, 9 |
| ANSI-SPARC | комитет SPARC Национального института стандартизации США (ANSI) | трёхуровневая архитектура систем управления базами данных | 1 |
| UML | Unified Modeling Language, «унифицированный язык моделирования» | язык диаграмм, в том числе диаграмм классов | 3, 4, 8 |
| CASE | Computer-Aided Software Engineering | программы для автоматизации проектирования | 4 |
| PK, FK, UK | Primary Key, Foreign Key, Unique Key: первичный, внешний, уникальный ключ | пометки ключей в атрибутах ER-диаграммы | 3, 4 |
| SQL | Structured Query Language, «язык структурированных запросов» | язык работы с реляционными базами | 9 |
| ННФ, 1НФ, 2НФ, 3НФ | ненормализованная форма, первая, вторая и третья нормальные формы | этапы нормализации отношения | 6 |
| НФБК | нормальная форма Бойса — Кодда | более строгий вариант третьей нормальной формы | 6 |
| ISAM | Indexed Sequential Access Method, «индексно-последовательный метод доступа» | одна из файловых организаций | 9 |

## Понятия

| Термин | Что значит | Глава |
|---|---|---|
| Модель данных | набор понятий для описания данных, связей между ними и ограничений | 1 |
| Внешняя, концептуальная, внутренняя модель | данные глазами пользователей, независимое от СУБД описание, отображение в выбранной СУБД | 1 |
| Концептуальное, логическое, физическое проектирование | три этапа проектирования базы данных | 1 |
| Тип сущности и экземпляр | группа однотипных объектов и один такой объект | 2 |
| Тип связи | набор осмысленных ассоциаций между типами сущностей | 2 |
| Атрибут | свойство сущности или связи | 2 |
| Простой, составной, однозначный, многозначный, производный атрибут | виды атрибутов по составу, числу значений и способу получения | 2 |
| Домен | набор допустимых значений атрибута | 2, 7 |
| Потенциальный, первичный, альтернативный, составной ключ | ключи, которые однозначно идентифицируют экземпляр сущности | 3 |
| Внешний ключ | атрибут, который ссылается на ключ другой таблицы | 3 |
| Сильная и слабая сущность | существует независимо или зависит от другой сущности | 3 |
| Кратность | сколько экземпляров одной сущности связано с одним экземпляром другой | 3, 8 |
| Степень участия | обязательное или необязательное участие сущности в связи | 3 |
| Нотация Чена | сущности прямоугольниками, связи ромбами | 4 |
| Нотация «воронья лапка» | связи линиями, «много» показывает значок-лапка на конце | 4 |
| Идентифицирующая связь | дочерняя сущность не существует без родительской (`--` в Mermaid) | 4 |
| Ловушка «разветвление» | неоднозначный путь между экземплярами сущностей | 5 |
| Ловушка «разрыв» | между экземплярами пути нет из-за необязательного участия | 5 |
| Нормализация | преобразование отношений для устранения избыточности и аномалий | 6 |
| Функциональная зависимость | значение одних атрибутов однозначно определяет значение других | 6 |
| Частичная зависимость | атрибут зависит от части составного ключа | 6 |
| Транзитивная зависимость | атрибут зависит от ключа через другой атрибут | 6 |
| Аномалия вставки, удаления, модификации | проблемы обновления данных при избыточности | 6 |
| Словарь данных | документация модели; также системный каталог СУБД | 7 |
| Метаданные | данные о данных | 7 |
| Класс | множество объектов с общими свойствами и поведением | 8 |
| Операция | действие, которое может выполнить объект класса | 8 |
| Видимость атрибута | кто может читать и менять атрибут: открытый, закрытый, защищённый | 8 |
| Ассоциация, агрегация, обобщение, зависимость | виды связей между классами | 8 |
| Класс-ассоциация | связь, у которой есть собственные атрибуты | 8 |
| Стереотип | пометка роли класса: сущность, граничный, управляющий | 8 |
| Файловая система | набор программ, у каждой из которых свои данные | 9 |
| Индекс (первичный, кластеризующий) | структура ускорения доступа к строкам таблицы | 9 |
| Денормализация | осознанное добавление избыточности ради скорости | 9 |
