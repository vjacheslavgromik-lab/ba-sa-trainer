## Блокеры и решения

- **Публикация.** Каждое слияние в `main` деплоится на GitHub Pages; пуш и слияние делаются только по вашему подтверждению.
- **Новые зависимости.** react-router-dom, vitest, jsdom, tsx, @testing-library/react, @testing-library/user-event, sql.js (+ @types/sql.js) и компоненты shadcn/ui на Radix. Лицензии разрешающие (MIT и аналогичные).
- **Решение по US-4.1.** Отправка всех ответов разом остаётся как есть.
- **Зависимость mermaid 12.3.0** (MIT) для ER-тренажёра: грузится только на странице тренажёра (около 810 КБ на этой странице).
- **Зависимости `remark-gfm` (MIT) и `yaml` (ISC, только для тестов).** `remark-gfm` отображает таблицы Markdown в теории; основной бандл вырос до 652 КБ (был 537 КБ). `yaml` разбирает пример спецификации OpenAPI в тесте. Внешний валидатор OpenAPI запустить не удалось, пример проверяется по правилам спецификации 3.1.1.
- **Формат ER (ADR-5, открытый вопрос 4).** Принят Mermaid `erDiagram` как в US-5.3.
- **Источники Postman и теории модуля 9.** `Integration_patterns` не описывает REST и HTTP, поэтому ссылки на него даны по аналогии; REST и HTTP опираются на RFC 9110, Google AIP-121/122, Postman Learning Center, спецификацию OpenAPI 3.1.1; диаграмма последовательности — на Вендрова п. 2.5.2. У документации Postman нет страницы о лицензии: на неё только ссылаемся, текст не копируем.
- **Определение API** в главе 1 помечено как рабочее определение курса: в Postman и Google такого определения нет.
- **Размер основного бандла.** После теории модулей 4, 7, 8, 5, 1, 6, 10 и 11 основной файл `index-*.js` вырос до 1 430 КБ (gzip 381 КБ): теория подключается сразу. Возможное улучшение — ленивая загрузка теории; не запрашивалось.
