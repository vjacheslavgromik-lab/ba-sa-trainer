## Блокеры и решения

- **Публикация.** Каждое слияние в `main` деплоится на GitHub Pages; пуш и слияние делаются только по вашему подтверждению.
- **Новые зависимости.** react-router-dom, vitest, jsdom, tsx, @testing-library/react, @testing-library/user-event, sql.js (+ @types/sql.js) и компоненты shadcn/ui на Radix. Лицензии разрешающие (MIT и аналогичные).
- **Решение по US-4.1.** Отправка всех ответов разом остаётся как есть.
- **Зависимость mermaid 12.3.0** (MIT) для ER-тренажёра: грузится только на странице тренажёра (около 810 КБ на этой странице, основной бандл 537 КБ).
- **Формат ER (ADR-5, открытый вопрос 4).** Принят Mermaid `erDiagram` как в US-5.3.
- **Источники Postman.** `Integration_patterns` не описывает REST и HTTP, поэтому ссылки на него даны по аналогии. У документации Postman нет страницы о лицензии: на неё только ссылаемся, текст не копируем.
